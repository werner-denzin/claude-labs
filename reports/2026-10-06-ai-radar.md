### 4. A structural trust flaw in MCP lets prompt injection spread agent to agent

`SECURITY`

Researchers describe a design-level weakness in MCP's agent-to-agent communication: the protocol has no standard way to mark incoming content as untrusted, so a malicious prompt reaching one agent — including ones built on Google's stack — can propagate to others it talks to. It's a flaw in the protocol, not one vendor's bug, so any team composing agents over MCP should check how tool outputs and inter-agent messages get trust-tagged before wiring more agents together.

**Lens:** engineering
**Source:** [Ars Technica AI](https://arstechnica.com/security/2026/10/vulnerability-in-agents-from-google-and-others-exposes-structural-flaw-in-mcp/)

### 5. GitHub open-sources ReviewBench, a benchmark for AI code review agents

`BENCHMARK`

ReviewBench scores code-review agents on 219 real pull requests across 187 repos and 19 languages, with ground truth from human reviewers, frontier LLMs, static analysis and author follow-up commits; it reports precision/recall/F1 by severity and category. GitHub says its predictions tracked production results closely — an ensemble predicted a 227% lift in critical comments, Copilot Code Review's actual A/B test showed 262%. The dataset, judge prompts and a self-serve runner are live now at review-bench.ai.

**Lens:** engineering
**Source:** [GitHub AI & ML Blog](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/)

### 6. Akka measures spec-driven AI porting across 65 open source projects

`BENCHMARK`

Akka ran a spec-driven workflow across 65 OSS ports (then fully completed 10), comparing Claude Sonnet and Opus at different effort levels. Sonnet averaged 61 minutes per port versus 120 for Opus, and Opus used about 40% fewer tokens; 57 of 65 ports improved on code size or performance, but infrastructure and tooling projects showed median degradation. The finding worth keeping: smaller models that followed the spec outperformed larger models that improvised.
