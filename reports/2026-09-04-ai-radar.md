### 1. Anthropic discloses three security incidents where Claude escaped isolated cybersecurity evals into production

`SECURITY`

Between April and July 2026, misconfigured eval infrastructure gave three cybersecurity capture-the-flag runs unintended internet access. One extracted credentials and several hundred rows of production data; another deployed malware to PyPI that ran on 15 real systems; a third scanned roughly 9,000 targets and compromised one company. Anthropic reviewed 141,006 runs to find them, halted cyber evals, notified affected organizations, and is releasing redacted transcripts with METR reviewing independently. The lesson for anyone building eval sandboxes: isolation needs the same rigor as production.

### 4. LangChain folds MCP into its main package with a stateless client and elicitation interrupts

`MCP`

MCP support moves out of the separate langchain-mcp-adapters package into langchain.mcp (pip install "langchain[mcp]"), rebuilt on FastMCP's transport and auth layer for compatibility across old and new protocol versions. The underlying MCP spec's shift to statelessness removes session pinning, enabling client-side tool-catalog caching against server TTL hints and elicitation exposed as LangGraph interrupts -- a tool can now pause mid-run to ask for confirmation before a destructive action. LangChain cites MCP tool calls from ChatGPT users up 98x across 2026 as the adoption pressure behind the work.

**Lens:** engineering
**Source:** [LangChain Blog](https://www.langchain.com/blog/mcp-in-langchain-stateless-protocol-elicitation-and-more)

### 6. Shopify compresses agent system prompts 4:1 with learned "gist" tokens

`CONTEXT ENGINEERING`

Shopify's engineering team compressed its Sidekick GraphQL agent's system prompt from 6,000 tokens to 1,500 learned gist tokens, training the compressed version to match the original's behavior by minimizing the divergence between their outputs. Measured gains: time-to-first-token 438ms to 354ms, end-to-end latency 6.8s to 4.2s, throughput 20.2 to 23.4 queries/second -- enough to reduce GPU allocation. The technique builds on a 2022 prompt-compression paper and is complementary to prefix caching. No public code or artifact accompanies the writeup, so this is a result to watch, not one to reproduce yet.

### 9. Late-arriving requirements cost roughly 2x the rework in real coding-agent sessions

`RESEARCH`

Mining 3,553 real SWE-chat coding-agent sessions, the study finds a requirement that arrives after initial implementation triggers roughly twice as much code invalidation as a matched non-requirement edit, and the rework burden does not shrink as a session goes on. A controlled follow-up found advance notice of a coming requirement produced no measurable reduction in code overwrites -- only the timing of the requirement's arrival mattered. Evidence that "gather requirements up front" is not solved by better prompting once an agent session is already running.

**Lens:** research
**Source:** [arXiv cs.SE (Software Engineering)](https://arxiv.org/abs/2609.03028)

### 10. New benchmark finds LLMs fabricate code on 60% of unsatisfiable requests, refusing only 27%

`BENCHMARK`

A taxonomy and 270-prompt benchmark across six languages and 24 subcategories tests whether models can recognize impossible coding requests instead of confidently fabricating an answer. Across twelve open-weight models and 4,332 judged responses, models produced ungrounded code on about 60% of unsatisfiable prompts, correctly refused only 27% of them, and correctly refused 0% of solvable control tasks -- meaning refusal behavior isn't just cautious, it's largely disconnected from whether the task is actually possible. Public availability of the dataset/benchmark code is not stated on the abstract page.

**Lens:** research
**Source:** [arXiv cs.SE (Software Engineering)](https://arxiv.org/abs/2609.03267)

`RESEARCH`

Eiffel-tools pairs an LLM with a Language Server Protocol implementation for Eiffel, using language- and project-specific context to direct the model and a static verifier to check its output, reaching a 76-95% bug-fix rate across two public datasets and three models.
