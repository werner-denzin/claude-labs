### 5. LangChain cut median agent cost 64% by moving model routing into the harness, not a gateway

`Harness engineering`

LangChain's Open SWE team ran a 973-thread A/B test routing each task's first message to one of three tiers (fast/balanced/performance) via a classifier built into the harness, not a generic model gateway — the case is that routing needs task context the harness already has. Result: 64% lower median cost per task with no measurable quality change; 56% of threads landed on the balanced tier, only 10% needed the strongest model. Cost per thread ranged $0.097 to $2.88, a 30x spread. The routing middleware is newly released and public.

### 9. Google researchers stop self-improving agents from memorizing their own eval tasks

### 14. Letting a separate agent keep generating adversarial tests beats fixing the test suite once, in a controlled TDD experiment

`Research`

GTDD has a tester agent keep generating new adversarial inputs round over round, using feedback from prior failures and a trusted evaluator that reduces counterexamples, instead of locking a test set at the start (the standard TDD assumption an adaptive coding agent can learn to satisfy without genuinely implementing the behavior). On a stateful key-value store benchmark, continuously regenerated tests produced lower failure rates than a single-generation baseline; giving the tester the source code added no further benefit. A concrete alternative to "write the tests first and stop."

### 19. Mutation testing finds a test suite that "passes" but never actually observes the bug it was built to catch

`Research`

The authors mutation-tested an invariant suite for a multi-session agent state layer and found a mutant that deleted event-identity deduplication survived every check. After repairing the suite, 5 of 10 adversarial mutants still survived — three because no fixture ever exercised the affected input path, two because no oracle could observe the corrupted state. Mapping "seven discriminating dimensions" of the input space and adding one fixture per uncovered dimension killed all five. A rebuttal to "the suite is green" as evidence the suite works.

**Lens:** research
**Source:** [arXiv cs.SE (Software Engineering)](https://arxiv.org/abs/2610.02928)
