### 1. Claude Code settings files expose thousands of secrets on GitHub

`SECURITY`

### 7. LangChain ships browser use and async subagents in Managed Deep Agents

`AGENT FRAMEWORK`

LangChain's Managed Deep Agents platform (v0.10, public beta, out now) adds two capabilities core to the agent-framework agenda. Browser use lets an agent declare a sandboxed browser via `define_browser(...)` and hand off logins to a human when a site needs credentials or 2FA, so secrets never pass through the model's traces. Async subagents run on their own thread with `"async": True`, so long tasks no longer block the orchestrator. Note: `connectors.mcp()` is removed in this release -- MCP servers must now be declared in `tools/mcp.ts` or `tools/mcp.py`.

**Lens:** engineering
**Source:** [LangChain Blog](https://www.langchain.com/blog/managed-deep-agents-browser-use-and-asynchronous-subagents)

### 10. Simon Willison: hide agent-written PR descriptions behind a collapsed `<details>` block

`PRACTICE`

Willison notes that Claude Code and Codex now write PR descriptions that are too thorough -- long enough that reviewers skim past the part that matters. His fix: wrap the full account of changes in a collapsed `<details><summary>` block in the PR template, so the reviewer sees a one-line summary by default and can expand for the agent's full reasoning. A small, concrete habit for any team whose PRs are agent-authored.

**Lens:** engineering
**Source:** [Simon Willison's Weblog](https://simonwillison.net/2026/Nov/9/details-summary/)
