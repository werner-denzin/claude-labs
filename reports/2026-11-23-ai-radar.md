### 2. Claude Code has been leaking secrets through its "Don't Ask Again" permission file

`SECURITY`

Approving a shell command with "don't ask again" writes it verbatim into `.claude/settings.local.json`, so any embedded credential gets saved to disk. Apiiro found 1,122 secrets across 63 orgs; GitGuardian found 31,088 exposed on public GitHub, 5,343 still valid. Generic scanners miss them because they sit inside shell commands. Fix: `git rm --cached` the file, gitignore it, rotate every credential it ever held, and stop typing secrets into commands.

**Lens:** engineering
**Source:** [InfoQ](https://www.infoq.com/news/2026/11/claude-code-leaking-secrets/)

### 7. "The Harness Is the New Operating System": QCon SF keynote maps agent scaffolding onto OS design

`HARNESS`

Manju Rajashekhar's QCon talk argues the harness, not the model, decides what an agent can do: context as virtual memory, interface as system calls, execution as process permissions. Concrete numbers: a 20-step task at 95% per-step reliability succeeds ~36% of the time, catching 80% of errors raises that to ~82%; moving a check from model to harness took GPT-5.2-Codex from 52.8% to 66.5% on Terminal-Bench 2.0 with no model change. Practical advice: read your agent's system prompt and tool list, then change one harness component and rerun what already works.
