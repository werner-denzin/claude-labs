### 17. "Who Broke Me?": execution-guided repair of silent dependency breaks

`RESEARCH`

Targets behavioral breaking changes — a dependency upgrade that breaks a downstream project without changing its interface, so there is no compiler error and often no documentation to point at the real cause. Existing LLM repair methods lean on compiler feedback or docs that simply do not exist here; this method instead uses execution evidence to find the real upstream API responsible, a gap that shows up constantly in agent-driven dependency bumps.

**Lens:** research
