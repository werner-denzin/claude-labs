## 🔴 High

### 1. VS Code starts retiring the Local harness for Copilot agent sessions

`HARNESS`

VS Code 1.146 deprecates the Local harness, the older runtime that coordinates model, context, and tools for Copilot agent sessions in the editor. The Microsoft Copilot harness, built on the Copilot SDK and shared with Copilot CLI and the GitHub Copilot app, has been the default since VS Code 1.143 and stays available during a three-month transition. Removal is set for February 2027; customizations don't convert automatically and need a compatibility review before then.

**Lens:** engineering
**Source:** [GitHub Changelog](https://github.blog/changelog/2026-11-16-vs-code-retires-the-local-harness-in-february-2027)

### 4. Google: a fully autonomous AI cyberattack has been observed in the wild for the first time

`SECURITY`

Google's Threat Intelligence Group found an AI framework, dubbed exploit_agent, on an exposed server that compared code before and after a patch, built a working exploit and ran it with no human in the loop. ### 5. Anthropic: the key to agent memory is knowing what to forget, not how much to store

`AGENT MEMORY`

Anthropic studied how Claude retains knowledge across long-running sessions and found selective notes beat exhaustive archives by a wide margin: in a Pokemon Red benchmark, Claude Fable 5 got four times as far as Sonnet 3.7 while keeping a handful of strategy files instead of more than 400.
