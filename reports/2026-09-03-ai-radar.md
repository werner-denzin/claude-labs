### 13. arXiv: code-retrieval benchmarks may overstate what coding agents can actually find

A new benchmark, ExecRetrieval, tests whether code-embedding retrieval -- a core component of coding agents and RAG code generation -- can tell functionally correct code from near-clone-but-buggy variants, not just lexically similar code. Existing benchmarks don't plant execution-verified single-edit bugs into the search pool, so today's reported retrieval scores may overstate real usefulness.
