## 🔴 High

### 1. Claude Code v2.1.259 adds org-wide MCP distribution and an unattended mode

Two changes matter for a company standardizing agent tooling. `managedMcpServers` lets an organization push HTTP/SSE MCP servers to every user through managed settings, using the same entry shape as .mcp.json. `--permission-prompts none` targets unattended headless hosts: anything that would prompt is denied automatically while the active permission mode still decides. Also recognises GitLab `glab mr` commands and adds `--json` to plugin validate.

**Lens:** engineering  
**Source:** [Claude Code](https://github.com/anthropics/claude-code/releases/tag/v2.1.259)
