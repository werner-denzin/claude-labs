### 6. LangChain: offload agent context to files instead of the context window

`CONTEXT ENGINEERING`

LangChain's Deep Agents framework argues long-running agents degrade as tool outputs and chat history fill the context window ("context rot"), and instead moves large results to files that the agent reads from a path rather than holding in memory — with long-term memory also stored as plain files portable across model swaps. The pattern is already implemented in the open-source `deepagents` package, not just proposed.

**Lens:** engineering
**Source:** [LangChain Blog](https://www.langchain.com/blog/context-engineering-deep-agents-remember)

### 7. LangChain: a retrieve-offload-delegate pattern for agent search tools

`CONTEXT ENGINEERING`

A companion LangChain post names three retrieval failure modes — inefficient search, oversized results, irrelevant context — and recommends the cheapest search that works (filename or keyword matching) before semantic search. The concrete pattern: run the search and write results to files, return only file paths to the main agent, then hand each file to a subagent that reads it and returns just the relevant facts.

**Lens:** engineering
**Source:** [LangChain Blog](https://www.langchain.com/blog/context-engineering-starts-with-retrieval)

### 8. Workday built its internal agent platform on LangGraph, cut prototyping from months to a day

Workday reports prototype setup dropped from 4-5 months to under a day in staging, and the team grew from 4 to about 30 people. ### 9. Stripe built a company-wide agent on Deep Agents in one week, now used by 83% of staff weekly

`CASE STUDY`

Stripe's "Kai" agent layers a Stripe-specific harness on LangChain's open-source Deep Agents rather than building the agent loop from scratch, using an S3-backed virtual filesystem, a sandbox exposed as a tool, and summarization middleware for long sessions. ### 12. Google: stale technical debt derails coding agents through "agent distraction"

`PRACTICE`

### 19. Coding agents lose the plot on degraded bug-report screenshots

`RESEARCH`

Coding agents increasingly receive UI screenshots in bug reports, but low resolution, compression artifacts or small text can stop vision-language models from identifying the right UI element or source file, and OCR-assisted fallbacks can propagate their own recognition errors. The paper proposes grounding image understanding in repository context to recover when the visual evidence alone isn't enough — a concrete gap for anyone routing screenshots into a coding agent's bug-triage flow.

**Lens:** research
**Source:** [arXiv cs.SE (Software Engineering)](https://arxiv.org/abs/2611.13026)
