### 19. ProdPilot uses an MCP server to catch production-readiness defects in vibe-coded apps

`MCP`

AI-assisted coding tools often produce apps that fail on first deployment — credentials left in source, missing security middleware, no container definition, no health endpoint. ProdPilot is a local Model Context Protocol server that independently audits Node.js projects for these operational defects rather than relying on free-form model-generated fixes, giving a checkable, repeatable layer on top of agent-written code.

### 20. A time-consistent benchmark protocol closes a leakage gap in SWE-agent evals

`EVALS`

Repository-aware coding-agent benchmarks often leak future information: solutions or related code that didn't exist at the historical cutoff point leak into the prompt or the knowledge graph the agent is evaluated against. This paper enforces strict zero-leakage isolation across a C++ and a JavaScript/TypeScript codebase, locking snapshots at a cutoff commit and evaluating only post-cutoff pull requests — a methodology fix relevant to anyone citing SWE-agent benchmark scores to justify a tool choice.

**Lens:** research
**Source:** [arXiv (cs.SE)](https://arxiv.org/abs/2611.17388)
