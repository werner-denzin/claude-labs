### 13. IBM ships LLMON, a markup language built to resist prompt injection

`GUARDRAILS`

IBM's Granite team released LLMON (LLM Object Notation), an XML-like markup that wraps prompt components in explicit tagged roles so structure isn't implicit or JSON-encoded, which it argues reduces exposure to indirect prompt injection hidden in data. Two 'experimental preview' models (granite-4.1-3b/8b-LLMON-preview) plus a GitHub toolkit shipped alongside. On the OPI prompt-injection benchmark the LLMON-wrapped models resisted injected instructions far better than the systems tested, while matching base Granite 4.1 Instruct on general capability — a real benchmark behind the claim, not just a format proposal.
