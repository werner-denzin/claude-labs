### 13. When should dependency-update PRs escalate to a repair agent?

`Research`

A new study frames triaging dependency-update pull requests as a "pre-agent routing" problem: most updates are routine, but a small subset need real compatibility repair, and invoking a coding agent on every one wastes model calls, CI time and review attention. It proposes lightweight signals to decide which updates should be escalated before running an agent on them, directly relevant to anyone running agents on routine PRs today.

**Lens:** research
**Source:** [arXiv cs.SE](https://arxiv.org/abs/2609.25911)

### 14. Machine unlearning aims to stop LLMs generating deprecated APIs

`Research`

LLMs used for code completion often suggest deprecated APIs because their training data includes code from older library versions. This paper evaluates machine unlearning as a fix, going further than prior work by actually verifying whether a model still exhibits the deprecated behavior and checking for unintended side effects elsewhere, rather than assuming a predefined replacement works. Relevant to anyone whose coding agent keeps suggesting APIs that no longer exist.

**Lens:** research
**Source:** [arXiv cs.SE](https://arxiv.org/abs/2609.25786)
